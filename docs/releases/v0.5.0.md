# Codex Session Canvas v0.5.0

**Release date:** 2026-11-23

## Highlights

- **Linked Context:** a successful Context Graph run is bound to its original Codex target Session, with an opt-in migration path for existing v0.4 runs.
- **Immutable provenance snapshots:** SHA-256 fingerprints for graph revisions, chosen source sessions, selected context segments and actually delivered (possibly redacted) prompts. Historical chat bodies are never stored in snapshot manifests.
- **On-demand context refresh:** explicitly inspect changed sources, review the proposed update, optionally redact it, and approve a follow-up turn in the *existing* Session. No automatic background reading or automatic reuse of previous task instructions.
- **Canvas UI:** inspect linked sessions, diff provenance, browse snapshot history and re-approve updated context.
- **Cross-platform packaging:** Windows-compatible Skill installer includes both v0.5 modules.

## Upgrade

Download the release ZIP and unpack it on your Windows machine. From PowerShell, run:

```powershell
py -3 install_skill.py --force
```

The `--force` option replaces the previous Skill installation. Back up any local edits to the Skill directory first. Existing Context Graphs, project registries and run manifests in the user's config area are not deleted by the installer.

Start the canvas inside a Codex project through `$codex-session-canvas` or `py -3 canvas.py --serve --open` from the source directory.

## Validation

- Windows and Linux GitHub Actions unit/integration tests, JS syntax and static export tests.
- Chromium browser smoke including Context Graph and linked listing.
- Five additional simulated end-user scenarios using disposable folders, mocked Codex calls and teardown assertions.
- Secure defaults: no silent session transcript reads; no persisted historical chat bodies; one-time approved execution; source-revision recheck.

**Limitation:** Live authenticated Codex Desktop `thread/resume` on the user's actual Windows machine is not validated by simulated CI. Some Codex versions may require manual resume/copy fallback. Existing v0.4 Windows live-runtime acceptance issues remain open.
